# 前言

为什么要写字体标准？

在当前互联网中比较难找到关于字体标准的资料，尤其是中文资料更少，导致很多人想要了解和学习字体相关的技术时候找资料困难。所以写这一本书，来帮助大家更好的学习和了解字体相关的技术标准。同时对自己来说也是一个很好的学习与理解过程。

这是一篇字体标准的中文翻译文档同时也会带上很多自己的理解在里面，因为原文很多地方不够详细或者难以理解。如果大家在阅读过程中发现有错误的地方，欢迎大家提 issue 指正。
